# Stock Intelligence AI — Step 1 Functional Demo

This is a frontend-only, fully interactive demo using simulated market/news/filing data.

## Run in Visual Studio Code

Requirements:
- Node.js 18+ (20+ recommended)

Commands:
```bash
npm install
npm run dev
```

Open the Local URL shown by Vite, normally:
http://localhost:5173
